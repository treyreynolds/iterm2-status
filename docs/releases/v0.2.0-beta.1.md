# v0.2.0-beta.1

The first public beta adds Codex CLI sessions to iTerm2's native Session Status
sidebar, alongside Claude Code when installed. Optional launcher profiles open
new agents. This independent community integration is MIT licensed.

## Install or upgrade

Follow the [README](../../README.md). Existing users can pull `main`, run
`python3 install.py`, then `python3 install.py doctor --live`. Start a fresh Codex
session and review the hooks in `/hooks`. ZIP users can extract the attached
archive and run the same installer. A SHA256 file accompanies the download.

## Changes

- Portable iTerm, Python, Codex, and bash/zsh/fish discovery and saved preferences.
- Prerequisite checks and redacted diagnostics for installation and support.
- Repeatable install, upgrade, rollback, and uninstall with configuration backups.
- Concurrency fixes for lifecycle events, approvals, resume, and late completion.
- Setup, troubleshooting, compatibility, privacy, contribution, and release docs.

## Evidence and limits

All 48 tests passed across Intel and Apple Silicon on macOS 14, 15, and 26 with
Python 3.9, 3.11, and 3.14. Real Codex 0.153.4 and iTerm2 3.7.0 installation,
upgrade/rollback, and bash/zsh/fish launcher execution passed on both architectures.
Local Codex 0.154.0 tests verified real approval, completion, interruption, resume,
and exit events reaching iTerm's API. See the [full evidence](../compatibility.md).

Use native iTerm panes with one foreground Codex session per pane. SSH, containers,
tmux/screen, and live delegated-agent behavior remain unverified. Abrupt termination
or a failed iTerm API report can leave stale status. Ordinary CLI startup can defer
its first status until a prompt. These limits are described in the compatibility doc.

Report bugs through [Issues](https://github.com/treyreynolds/iterm2-status/issues/new/choose)
with `python3 install.py doctor --json`. Send security findings through
[private vulnerability reporting](https://github.com/treyreynolds/iterm2-status/security/advisories/new).
